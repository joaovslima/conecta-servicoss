# Conecta Serviços

Aplicativo em JavaScript e React Native para conectar clientes e profissionais de serviços em Fortaleza.

**[Abrir demonstração](https://joaovslima.github.io/conecta-servicoss/)**

## Tecnologias

- JavaScript
- React Native
- Expo
- React Native Web

## Status

Protótipo acadêmico com dados fictícios em memória. Os dados são reiniciados ao atualizar a página.
